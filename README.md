Exercício da aula 02 de **React** do **Serratec (2021)**: uma calculadora de **Índice de Massa Corporal (IMC)**.

## Funcionalidades

- O usuário informa **peso e altura**
- A aplicação calcula o IMC e mantém um **histórico dos resultados**, do mais recente para o mais antigo

## Destaques técnicos

- Componentes `Formulario`, `Card` e `ResultadoIMC`
- Estado com `useState`, comunicação filho → pai por *callback* (`aoSalvar`) e renderização de listas com `map`

## Como executar

```bash
npm install
npm start
```

A aplicação abre em `http://localhost:3000`.
